# Moodboard
## Agatha Christie: El gabinete de misterios

El moodboard reúne las referencias visuales que definen la identidad del sitio web de Agatha Christie: El gabinete de misterios.

Las referencias están enfocadas en una estética de misterio, investigación y literatura, tomando como inspiración elementos relacionados con gabinetes, bibliotecas, archivos, libros, detectives y la obra de Agatha Christie.

Se trabajan referencias de:

- Tipografía  
- Paleta de color  
- Texturas  
- Composición  
- Fotografía  
- Elementos relacionados con el misterio y la investigación  
- Estética editorial y clásica

El moodboard completo se encuentra desarrollado en Adobe Illustrator que mandé en pdf con conjunto de otras referencias visuales; Y funciona como referencia visual para definir la apariencia y el lenguaje gráfico de la página web.

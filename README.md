# Colección Agatha Christie-contenido estructurado
Contenido estructurado con IA, Markdown y HTML semántico

Este repositorio funciona como una plantilla para organizar información y transformarla en una página web utilizando Markdown, HTML, CSS e IA como herramienta de apoyo.

## Sobre el proyecto
Este proyecto nace de mi interés por la lectura, especialmente por las historias de misterio, y por la curiosidad de conocer cómo se pueden reunir y presentar las obras de un mismo autor a través de una colección.

Elegí trabajar con la Colección de Agatha Christie de la editorial de Planeta DeAgostini porque me parece interesante cómo una serie de libros puede convertirse en un objeto de colección. Además de reunir distintas obras (famosas) de la autora  la colección construye una identidad visual a través de sus portadas, formatos y elementos editoriales.

## ¿Qué buscó en este proyecto?

Quiero que mi página divulge y organizé información sobre colecciones literarias, tomando en este caso la colección de Agatha Christie de 2023-2025.

La intención es que el usuario pueda conocer de una manera más visual y sencilla: qué libros son parte de la colección, cómo está organizada, cuándo fue publicada, quiénes son los personajes y detectives de las historias, qué características tienen sus portadas, cómo funciona, cómo se comercializa y quién fue Agatha Christie.

## Objetivo

Buscó mostrar que una colección de libros no solamente puede entenderse como un conjunto de publicaciones, sino también como un sistema que reúne información editorial, visual, comercial y cultural.
